# JavaScript DOM & Timing Practice

This project contains a simple HTML page that demonstrates:

- DOM manipulation using `getElementById()` and `querySelector()`
- `textContent` and `style` changes
- `addEventListener()` usage
- `setTimeout()` for delayed message display
- `setInterval()` and `clearInterval()` for counter logic
- callback function usage in `greet(name, callback)`

## Open the page

Open `index.html` in a browser to view the demo.
